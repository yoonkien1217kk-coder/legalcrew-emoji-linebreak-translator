# Slack → SNS 이모지 번역기 설계

## 목표

Slack에서 복사한 문구 속 `:smile:` 같은 이모지 단축어를 인스타그램과 페이스북에서 바로 표시되는 유니코드 이모지로 바꾼다. 사용자는 결과를 한 번에 복사할 수 있어야 하며, 결과에는 단축어·설명·깨진 이미지가 남지 않는다.

## 범위

- 일반 Slack 이모지 단축어를 유니코드 이모지로 자동 변환한다.
- 문장, 공백, 줄바꿈은 그대로 유지한다.
- 알려진 커스텀 이모지 이름은 가까운 유니코드 이모지로 자동 변환한다.
- 모르는 커스텀 이모지는 사용자가 유니코드 이모지를 한 번 지정한다.
- 사용자가 지정한 대응값은 브라우저 `localStorage`에 저장한다.
- 변환 결과를 클립보드에 복사한다.
- 변환은 전부 브라우저에서 수행하며 입력 내용을 서버로 보내지 않는다.

로그인, Slack OAuth, 게시물 직접 발행, 이미지 합성, 사용자 간 매핑 공유는 첫 버전에 포함하지 않는다.

## 사용자 흐름

1. 사용자가 Slack 문구를 입력란에 붙여넣는다.
2. 앱이 텍스트와 줄바꿈을 보존하면서 `:emoji_name:` 토큰을 찾는다.
3. 기본 사전 또는 저장된 사용자 매핑이 있으면 즉시 실제 이모지로 바꾼다.
4. 매핑이 없는 토큰은 결과에서 `□`로 표시하고 미확인 목록으로 분리한다.
5. 사용자가 각 미확인 항목에 실제 이모지를 지정하면 결과가 즉시 갱신된다.
6. 사용자가 `결과 복사`를 눌러 인스타그램이나 페이스북에 붙여넣는다.

## 화면 구성

한 페이지에 다음 요소만 둔다.

- 서비스 설명과 개인정보 보호 안내
- Slack 문구 입력 영역
- 변환 수와 미확인 수를 보여주는 짧은 상태 표시
- 미확인 커스텀 이모지별 대체 이모지 입력 영역
- 실제 SNS에 붙을 형태 그대로 보여주는 결과 영역
- 결과 복사 및 전체 지우기 버튼

모바일에서도 입력과 복사 버튼을 쉽게 누를 수 있게 단일 열 레이아웃을 기본으로 한다. 키보드 포커스, 명확한 레이블, 충분한 대비를 제공한다.

## 구현 구조

의존성이나 서버가 없는 정적 HTML/CSS/JavaScript 앱으로 만든다.

- `dist/index.html`: 화면 구조
- `dist/styles.css`: 반응형 표현
- `dist/emoji-map.js`: 기본 및 자주 쓰는 Slack 별칭 매핑
- `dist/app.js`: 토큰 변환, 사용자 매핑 저장, 복사 UI
- `tests/translator.test.mjs`: Node 내장 테스트 러너로 변환 로직 검증

변환 함수는 UI와 분리된 순수 함수로 작성한다. 토큰은 영문자, 숫자, 밑줄, 더하기, 빼기로 구성된 `:name:`만 인식해 시간 표기나 일반 콜론 문장을 건드리지 않는다. 피부색 결합처럼 별도 별칭이 있는 항목은 완성된 유니코드 시퀀스로 매핑한다.

## 오류 처리

- 빈 입력에서는 빈 결과와 안내 문구를 보여준다.
- 미확인 단축어는 결과에서 `□`로 표시하고, 사용자가 지정하기 전에는 복사 버튼을 비활성화한다. 따라서 단축어나 깨진 표시가 SNS로 넘어가지 않는다.
- 클립보드 API가 실패하면 결과를 자동 선택하고 수동 복사 안내를 표시한다.
- 손상된 `localStorage` 데이터는 무시하고 기본값으로 복구한다.

## 검증

Node 내장 테스트로 다음을 확인한다.

- 여러 기본 별칭 변환
- 문장과 줄바꿈 보존
- 같은 별칭 반복 변환
- 사용자 커스텀 매핑 적용
- 미확인 별칭 수집 및 복사 차단 조건
- 일반 콜론과 URL 비변환

추가로 정적 파일 구문 검사와 브라우저에서의 붙여넣기·선택·복사 흐름을 확인한다.
